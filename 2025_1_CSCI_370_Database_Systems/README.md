# CSCI 370 - Database Systems

*Spring, '25*

## *Overview*

An introduction to the use and operating principles of database management systems. Topics include data entities and relationships, data modelling using Entity-Relationship Diagrams, hierarchical, network and relational models of databases, query language, physical representation of data in secondary storage, relational algebra and calculus as applied to the design of databases, security and integrity in the context of concurrent use, and basic ethical issues associated with database design and use. [1]

## Contents:

### Assignment\_7\_Package\_Ordering\_Database\_Program\_in\_Cpp\_and\_Oracle\_SQL

*"This program simulates a co-op food package ordering system where members can place orders, manage their accounts, and unsubscribe from the service. It uses a C++ command-line interface connected to an Oracle SQL database to store and retrieve member account information and order details."* [2]

### Assignment\_8\_Package\_Ordering\_Database\_Summary\_Report\_Program\_in\_Cpp\_and\_Oracle\_SQL

*"This C++ program connects to an Oracle database to generate a summary report for a specified year based on a member account number. It queries member order history and, if applicable, producer supply records, then outputs the results to a text file with formatted member/producer information."* [2]

### Term\_Project\_Rideshare\_Database\_Program\_in\_Cpp\_and\_Oracle\_SQL

*"This is a rideshare database management system written in C++ that connects to an Oracle SQL database to track trips, vehicles, members, and gas prices. The program allows drivers to log trips with passengers, automatically calculate costs based on fuel consumption and gas prices, and update member account balances accordingly. It also provides administrative features to query trip statistics, detect overlapping/invalid trips, manage gas prices, and view member account information. The application simulates a complete rideshare service backend with user input validation and multi-step transaction handling."* [3]
