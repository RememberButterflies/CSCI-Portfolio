# Term\_Project\_Rideshare\_Database\_Program\_in\_Cpp\_and\_Oracle\_SQL

CSCI 370 - Database Systems*, Spring, '24*

## *Overview*

*"This is a rideshare database management system written in C++ that connects to an Oracle SQL database to track trips, vehicles, members, and gas prices. The program allows drivers to log trips with passengers, automatically calculate costs based on fuel consumption and gas prices, and update member account balances accordingly. It also provides administrative features to query trip statistics, detect overlapping/invalid trips, manage gas prices, and view member account information. The application simulates a complete rideshare service backend with user input validation and multi-step transaction handling."*  [1]
