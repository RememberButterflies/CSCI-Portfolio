# Lab\_4\_Three\_Way\_Light\_Switch\_in\_Verilog

CSCI 355 - Digital Logic and Computer Organization, Fall*, '24*

## *Overview*

*"This program implements a \*\*three-way light switch\*\* in Verilog, a digital logic circuit where a light can be controlled by three independent switches (x1, x2, x3). The light turns on only when an odd number of switches are in the "on" position (1), which is a common real-world electrical configuration found in homes where lights can be toggled from multiple locations."* [1]
