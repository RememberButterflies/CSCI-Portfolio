# CSCI 330 - Programming Languages

*Spring, '24*

## *Overview*

The fundamental concepts of imperative and applicative programming languages. Topics include the description of data types, variable assignment and sharing, sequencing, iteration and recursion, parameter passing mechanisms, and type checking. [1]

## Contents:

### Lab\_2\_Let-over-Lambda

*"This Common Lisp program implements a \*\*grade management system\*\* using the let-over-lambda closure pattern, creating dispatcher functions that encapsulate grade data (department, course number, credits, letter grade) and provide methods to retrieve, validate, and compare grades. The system calculates weighted GPAs and checks whether actual course grades meet prerequisite requirements across multiple courses."&#32;*[2]

### Lab\_3\_Lisp\_sbcl\_Macros

*"This program implements Common Lisp macros and functions to validate academic course grades and verify whether actual grades meet required course prerequisites. The test suite (test\_lab3.cl) comprehensively validates the macros by checking grade format validation, course matching, grade comparisons, and the variadic \`reqPassed\` function that determines if any actual course in a list satisfies a course requirement."&#32;* [2]

### Lab\_6\_Cpp\_Function\_Templates\_and\_Variadic\_Operations

*"This program demonstrates C++ function templates and variadic operations by testing various unary and binary functions across multiple data types (bool, int, float, double, long, string, and char). It uses template functions like \`apply()\`, \`sumDiffs()\`, and \`chosenMin()\` to apply these functions in generic ways, showcasing how templates enable code reuse while maintaining type safety."* [2]
