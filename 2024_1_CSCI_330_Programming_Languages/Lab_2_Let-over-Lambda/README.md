# Lab\_2\_Let-over-Lambda

CSCI 330 - Programming Languages, S*pring, '24*

## *Overview*

*"This Common Lisp program implements a \*\*grade management system\*\* using the let-over-lambda closure pattern, creating dispatcher functions that encapsulate grade data (department, course number, credits, letter grade) and provide methods to retrieve, validate, and compare grades. The system calculates weighted GPAs and checks whether actual course grades meet prerequisite requirements across multiple courses."* *&#32;*[1]
