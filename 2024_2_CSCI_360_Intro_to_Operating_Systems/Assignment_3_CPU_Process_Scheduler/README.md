# Assignment\_3\_CPU\_Process\_Scheduler

CSCI 360 - Intro to Operating Systems, Fall*, '24*

## *Overview*

*"This is a \*\*CPU Process Scheduler\*\* that implements multiple scheduling algorithms to manage task execution. The program reads a list of tasks (with name, priority, and CPU burst time) from a file, then simulates scheduling them using different algorithms: First Come First Serve (FCFS), Shortest Job First (SJF), Round Robin (RR), Priority-based (PR), and Priority with Round Robin (PR-RR). Depending on which scheduling implementation is compiled, the scheduler picks and executes tasks in the appropriate order, removing them from the list once their CPU burst is complete. This demonstrates how different scheduling strategies affect task execution order and efficiency in operating systems."* [1]

## Technology

This program implement following CPU scheduling algorithms:

1. First Come First Serve (FCFS)
2. Shortest Job First (SJF)
3. Priority (PR)
4. Round Robin (RR)
5. Priority with Round Robin(PR-RR)
