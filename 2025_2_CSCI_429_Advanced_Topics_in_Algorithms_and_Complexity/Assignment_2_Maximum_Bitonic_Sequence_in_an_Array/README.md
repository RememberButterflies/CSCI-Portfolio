# Assignment\_2\_Maximum\_Bitonic\_Sequence\_in\_an\_Array

CSCI 429 - Advanced Topics in Algorithms and Complexity*, Fall, '25*

## *Overview*

*"This program finds the \*\*maximum bitonic subsequence\*\* (MBS) in an array, where a bitonic sequence is one that strictly increases up to a peak and then strictly decreases. It uses dynamic programming with memoization to efficiently compute, for each potential peak position, the length of the longest increasing sequence to its left and the longest decreasing sequence to its right, then combines these to find the overall maximum bitonic subsequence length."*  [1]
