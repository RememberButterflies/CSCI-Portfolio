# Assignment\_1\_Optimal\_Cost\_of\_Binary\_Search\_Tree

CSCI 429 - Advanced Topics in Algorithms and Complexity*, Fall, '25*

## *Overview*

*"This program solves the Optimal Binary Search Tree problem, which finds the minimum cost of organizing a set of sorted keys with given search frequencies into a binary search tree structure. The user can initialize an array with keys and their frequencies, then calculate the optimal cost using dynamic programming with memoization."*  [1]
