# CSCI 429 - Advanced Topics in Algorithms and Complexity

*Fall, '25*

## *Overview*

This course examines selected emerging and advanced topics in Algorithms and Complexity Theory. Topics may include: advanced techniques for algorithm analysis; complexity classes; algorithmic techniques in graph theory, combinatorics, and optimization; approximation algorithms; distributed and parallel algorithms; probabilistic algorithms; online algorithms; quantum algorithms. ## Contents:

### Assignment\_1\_Optimal\_Cost\_of\_Binary\_Search\_Tree

*"This program solves the Optimal Binary Search Tree problem, which finds the minimum cost of organizing a set of sorted keys with given search frequencies into a binary search tree structure. The user can initialize an array with keys and their frequencies, then calculate the optimal cost using dynamic programming with memoization."* [2]

### Assignment\_2\_Maximum\_Bitonic\_Sequence\_in\_an\_Array

*"This program finds the \*\*maximum bitonic subsequence\*\* (MBS) in an array, where a bitonic sequence is one that strictly increases up to a peak and then strictly decreases. It uses dynamic programming with memoization to efficiently compute, for each potential peak position, the length of the longest increasing sequence to its left and the longest decreasing sequence to its right, then combines these to find the overall maximum bitonic subsequence length."* [2]

### Term\_Research\_Paper

*"This paper examines two scheduling algorithms—Coffman & Graham's Algorithm A (O(n²)) and Sethi's improved linear labeling and scheduling algorithm (O(nα(n)+e))—that optimally schedule computational tasks on two-processor systems represented as directed acyclic graphs. Both algorithms label tasks based on their partial order dependencies and then produce optimal schedules, with Sethi's approach achieving significantly better running time through clever use of levels, edge stacks, and disjoint set merging techniques."&#32;*[3]
