# CSCI 261 - Computer Architecture and Assembly Language

*Fall, '23*

## *Overview*

An introduction to computer organization, and machine and assembly languages. Topics include data representation, the instruction set and addressing modes of a chosen processor, procedures and parameter passing, and the use of operating system services. [1]

The assignments in this course were given to the students as structured but incomplete software. All assignments had their makefile, main, headers and test cases included. The students work of the assignments were to write the functions (including how they might call each other.) Because this repository is meant to showcase my coding skills and experience, and is not intended to provide usable software, this repository contains only the source code that I wrote and any associated README's.

## Contents:

### Assignment\_1\_Computer\_Number\_Systems

*"This program provides a set of utility and conversion functions in C for handling and validating strings representing numbers in various formats, including decimal, binary, real, and fixed-point representations. Its purpose is to facilitate conversions between these number systems, such as transforming decimal integers to binary or real numbers to fixed-point binary, as part of an educational assignment on computer number systems and architecture."&#32;*[2]

### Assignment\_2\_Signed\_Number\_Systems

*"This C program implements a set of functions to convert numbers between various signed number system representations, including decimal, binary, sign-magnitude, two's complement, biased-127, and floating-point formats, as part of an assignment on computer architecture and assembly language. Its purpose is to demonstrate and validate the conversion processes for handling signed integers and real numbers in different binary encodings, ensuring correctness within specified ranges and formats."* [2]

### Assignment\_3\_Integer\_Arithmetic

*"This is a Computer Architecture assignment that implements integer arithmetic operations by converting between decimal and binary (two's complement) representations. It performs addition, subtraction, and multiplication on signed integers by manipulating their binary representations using bit-level operations like one-bit addition and two's complement conversion."* [3]

### Assignment\_4\_ARMv8\_Assembly\_Code

*"This program implements multiple approaches to calculating Fibonacci sequences in ARMv8 assembly language (iterative, recursive, and dynamic programming methods). It generates Fibonacci numbers up to a user-specified index and displays the sequence using a formatted output function."* [4]

### Assignment\_5\_Floating\_Point\_Arithmetic

*"This program implements IEEE 754 single-precision floating-point arithmetic operations, including conversion functions between decimal, binary, two's complement, and floating-point representations. It provides utility functions for bit manipulation, validation of different number formats, and arithmetic operations like addition, subtraction, and multiplication on signed integers and floating-point numbers."* [3]
