# Assignment\_2\_Signed\_Number\_Systems

CSCI 261 - Computer Architecture and Assembly Language, *Fall, '23*

## *Overview*

*"This C program implements a set of functions to convert numbers between various signed number system representations, including decimal, binary, sign-magnitude, two's complement, biased-127, and floating-point formats, as part of an assignment on computer architecture and assembly language. Its purpose is to demonstrate and validate the conversion processes for handling signed integers and real numbers in different binary encodings, ensuring correctness within specified ranges and formats."&#32;*[1]

## Usage

The functions convert numbers from different number systems to other systems;

1. Converts any signed integer number into a sign magnitude binary number.
2. Converts any sign magnitude binary number into a signed integer number.
3. Converts any signed integer number into a tows complement binary number.
4. Converts any tows complement binary number into a signed integer number.
5. Converts any signed integer number into a biased-127 binary number.
6. Converts any biased-127 binary number into a signed integer number.
7. Converts any signed real number into a floating point binary number.
8. Converts any floating point binary number into a signed real number
