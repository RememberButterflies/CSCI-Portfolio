# Assignment\_3\_Integer\_Arithmetic

CSCI 261 - Computer Architecture and Assembly Language, *Fall, '23*

## *Overview*

*"This is a Computer Architecture assignment that implements integer arithmetic operations by converting between decimal and binary (two's complement) representations. It performs addition, subtraction, and multiplication on signed integers by manipulating their binary representations using bit-level operations like one-bit addition and two's complement conversion."&#32;*[1]

## Usage

The functions do integer arithmetic operations.

1. Adds 2 two's complement binary numbers.
2. Subtracts a two's complement binary number from another.
3. Multiply 2 two's complement binary numbers.
4. Divides a two's complement binary number from another.
5. Adds 2 signed integer numbers.
6. Subtracts a signed integer number from another.
7. Multiply 2 signed integer numbers.
8. Divides a signed integer number from another.
