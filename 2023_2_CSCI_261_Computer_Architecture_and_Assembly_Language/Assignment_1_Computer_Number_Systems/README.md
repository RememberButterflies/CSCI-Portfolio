# Assignment\_1\_Computer\_Number\_Systems

CSCI 261 - Computer Architecture and Assembly Language, *Fall, '23*

## Overview

*"This program provides a set of utility and conversion functions in C for handling and validating strings representing numbers in various formats, including decimal, binary, real, and fixed-point representations. Its purpose is to facilitate conversions between these number systems, such as transforming decimal integers to binary or real numbers to fixed-point binary, as part of an educational assignment on computer number systems and architecture."&#32;*[1]

## Usage

The functions converts numbers from different number systems to other systems;

1. Decimal number to a binary number.
2. Binary number to a decimal number.
3. Real number to a fixed point number.
4. Fixed point number to a real number
