# CSCI 260 - Data Structures

*Fall, '23*

## *Overview*

An examination of various methods of representing and manipulating data, including internal representation of data, stacks, queues, linked lists, trees and graphs. Analysis of algorithms will also be discussed extensively.[1]

## Contents:

### Assignment\_2\_AVL\_Binary\_Search\_Tree

*"This program implements an AVL-style binary search tree with insertion, deletion, search, traversal, height, min/max, inorder successor, and node distance operations. It reads initial tree values and then lets the user perform repeated interactive BST operations until quitting."&#32;*[2]

### Assignment\_4\_Heap\_Sort

*"This C++ program implements a heap sort algorithm, allowing users to input an array of integers, check if it's a valid max-heap, convert it into one if necessary, extract the maximum value (peak), and then sort the array in ascending order using heap operations. Its purpose is to demonstrate key heap data structure concepts, including heapification, heap validation, and sorting, as part of an educational assignment."&#32;*[2]

### Assignment\_5\_Directed\_Graph\_Bellman\_Ford

*"This program implements a directed graph data structure with multiple graph traversal and analysis algorithms, including breadth-first search (BFS), depth-first search (DFS), cycle detection, and the Bellman-Ford shortest path algorithm. Users can interactively build a weighted directed graph and then perform various operations to analyze its properties, such as finding shortest paths, detecting negative cycles, and traversing the graph in different orders."* [2]
