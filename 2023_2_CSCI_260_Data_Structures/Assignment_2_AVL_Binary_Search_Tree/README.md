# Assignment\_2\_AVL\_Binary\_Search\_Tree

CSCI 260 - Data Structures, *Fall, '23*

## Overview

*"This program implements an AVL-style binary search tree with insertion, deletion, search, traversal, height, min/max, inorder successor, and node distance operations. It reads initial tree values and then lets the user perform repeated interactive BST operations until quitting."&#32;*[1]

## Step by Step execution requirement:

1. The user should be asked to enter the number of nodes in the tree.
2. Based on the number of nodes entered by the user, the program should ask for the data to be inserted in the BST.
3. As the user enters the data, the program should make BST by inserting nodes.
4. While deleting a node, implement all the possible cases (deleting a leaf node, a node with one child and a node with two children)
5. For finding in order successor of a node implement all possible cases (when the node is the largest in the tree, when the node has right child and when the node doesn’t have a right child)
6. Plagiarism, copying or cheating would lead to zero marks for the submitted assignment.
7. Program should ask user to enter choice to do the operation.
8. Please add comments where actual logic is coded for each operation
9. If user enters a number other than 1 to 11, the program exits.
