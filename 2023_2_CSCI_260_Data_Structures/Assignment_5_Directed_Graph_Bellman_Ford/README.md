# Assignment\_5\_Directed\_Graph\_Bellman\_Ford

CSCI 260 - Data Structures, *Fall, '23*

## *Overview*

*"This program implements a directed graph data structure with multiple graph traversal and analysis algorithms, including breadth-first search (BFS), depth-first search (DFS), cycle detection, and the Bellman-Ford shortest path algorithm. Users can interactively build a weighted directed graph and then perform various operations to analyze its properties, such as finding shortest paths, detecting negative cycles, and traversing the graph in different orders."&#32;*[1]
